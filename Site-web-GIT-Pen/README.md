# GIT Pen : site vitrine d'un stylo, codé à la main

> **Jean-Pierre Gallego Santillan** et **Armin** ([@ar-br](https://github.com/ar-br)) · Apprentis informaticiens au GIT · Projet final web · Octobre 2026

**Mots-clés :** `HTML` `CSS` `JavaScript` `Responsive` `Flexbox / Grid` `Travail en binôme` `Live Share`

> [!NOTE]
> **En bref** : pour le projet final du cours web, nous avons créé à deux le site vitrine d'un stylo, le **GIT Pen** (le stylo de notre école), présenté comme le produit d'une marque suisse haut de gamme. Le fil rouge, c'est « démonter pour comprendre » : quand on fait défiler la page, le stylo se démonte pièce par pièce. Tout le site est codé à la main en HTML, CSS et JavaScript, sans framework.

## Ce que contient le site

- **3 pages** : l'accueil, la page des finitions (trois couleurs avec leur prix) et une page contact.
- **Un menu qui reste en haut** (sticky) et une navigation par ancres.
- **Une animation vidéo pilotée par le défilement**, avec une ligne de progression.
- **Un formulaire de contact vérifié en JavaScript**, avec un message d'erreur par champ.
- **Un site adapté au téléphone**, testé jusqu'à 320 × 480.
- **Une mise en page propre** : un seul fichier CSS avec des variables, Flexbox et Grid, et des animations au survol.

## Comment on a travaillé

- **À deux en même temps**, sur les mêmes fichiers, avec Live Share dans VS Code. Ma partie principale : la **structure HTML** des pages. Armin s'est occupé surtout de l'image d'accueil et du CSS.
- **Par petites étapes** testées une par une dans le navigateur (Live Server).
- **L'IA de façon encadrée** : les visuels du stylo ont été générés par IA, et l'animation au défilement a été réalisée avec l'aide de Claude Code, d'abord sur une page de test séparée, puis intégrée et expliquée ligne par ligne dans le rapport.
